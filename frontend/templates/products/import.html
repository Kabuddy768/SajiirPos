CSV Template & Guidelines

Ensure your CSV includes the following column headers. Capitalization does not matter.

Header Required Description
name Yes The full name of the product.
sku No Unique SKU. If left blank, a random one will be generated.
barcode No Unique barcode code. Must not match any existing product.
category No Category name. Created automatically if it doesn't exist. Defaults to "General".
unit No Unit short name (e.g. pcs, kg). Defaults to "pcs".
cost_price No Supplier cost price (e.g. 150.00). Defaults to 0.00.
selling_price No Retail selling price (e.g. 200.00). Defaults to 0.00.
